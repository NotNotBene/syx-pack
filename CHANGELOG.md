# Changelog

Newest version first.

## v35 – 2026-11-13 (first public release)

Game version: Songs of Syx 0.71.44 (v71).

- New name and interface: Syx Pack, header with version and game version, compact toolbar (Select, Pan, Build, Copy, Stamp, Capture, Export), build bar on the map (Room, Road, Wall, Door, Ceiling, Erase), tabs left (Buildings, Templates) and right (Inspect, Views, Economy, Plan), zoom buttons, status bar, quick search (Ctrl+K).
- Houses in rows of 1–9 like in the game.
- Interface fully in English.

Included from earlier, unpublished versions (v1–v34):

- District planning with walls, roads, doors, ceilings, fixed-size rooms and house rows; multi-selection with move, rotate and delete.
- Furniture editor and auto-furnish with game rules (workers, efficiency, isolation, quality, mandatory furniture check).
- Built-in templates for 37 × 37 blocks, street-grid generator with street width, own templates with categories.
- Production, consumption, costs, upkeep, bonuses and climate, production chain, commute and storage analysis, roundness view.
- Better Blueprints export (furniture, recipe, upgrade) and import (single lines, `AreaBlueprints.json`, `SavedPrints`); stamping over existing buildings.
